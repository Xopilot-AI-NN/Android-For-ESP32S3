# Локальная правка trouble-host 0.5.1

Исходники опубликованного crate сохранены с его лицензиями.
Единственная функциональная правка — в `connection_manager.rs`, обработка
неуспешного key exchange (`AUTHENTICATION_FAILURE`).

Пока отправка HCI Disconnect ожидает выполнения, событие завершения disconnect
может уже удалить соединение. Повторный `disconnected()` возвращает `NotFound`;
прежний `unwrap!` вызывал panic всего устройства. Теперь ошибка записывается
в trace и соединение не удаляется повторно. Успешная аутентификация, шифрование
и требования безопасности HID не ослабляются.

Проверка сборкой не заменяет проверку сопряжения на физическом телефоне/ПК.
После изменения HID Report Map удалите старое сопряжение на стороне хоста,
чтобы он заново прочитал характеристики клавиатуры.
