# Файлы

Код приложения: [main.rs](./main.rs), [view.rs](./view.rs).

Колёсико перемещает фокус. Один физический щелчок выбирает элемент, два открывают
файл или папку, три открывают действия: открыть, переименовать, копировать,
вырезать, удалить, свойства. Для распознавания серии есть пауза 350 мс.
Поворот или длинное нажатие отменяют незавершённую серию.

Нижний ряд: создать / действия / вставить / вверх. Создать позволяет выбрать
папку, файл, TXT или JSON. Копирование и вырезание сохраняют источник в буфере;
перейдите в целевую папку и выберите вставку. Копирование дерева папки выполняется
поэтапно; при ошибке уже созданные элементы остаются.

Текстовые файлы открываются встроенным построчным редактором UTF-8 до 64 КиБ.
В документе один щелчок выбирает строку, два редактируют, три открывают меню
редактора. На экранной клавиатуре и в меню обычное нажатие действует сразу.
JPEG/PNG передаются Галерее; другие бинарные форматы редактор не преобразует.

Хранилище WFS ограничено 32 записями каталога, включая папки, и UTF-8-путями
до 80 байт. Потоковые файлы через ADB — до 16 МиБ, если в userdata доступен
выделенный 64-МиБ пул. Это собственная ограниченная ФС, не FAT/ext4.

`/sdcard/Documents` в ADB — совместимый псевдоним корня документов `/sdcard`.
Обои отдельно: `/sdcard/Wallpapers/name.png`, PNG 240×280, до 320 КиБ.
Галерея читает обычные фотографии без ограничения размером экрана;
прогрессивный JPEG и interlaced PNG пока не поддерживаются.
