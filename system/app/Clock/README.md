# Часы

Пять вкладок: **Будильники / Мировые часы / Таймеры / Секундомер / Режим сна**.
Колесо сразу меняет содержимое над нижними значками. Сам выбор вкладки
не запускает таймер, секундомер и не меняет настройки.

Нажатие открывает настройку будильника, часового пояса или таймера; на вкладке
секундомера запускает/приостанавливает отсчёт, двойное нажатие сбрасывает его.
«Назад» и Home возвращают циферблат. Сейчас доступны один будильник и один
таймер; название вкладок не означает несколько одновременных.

На вкладке сна нажатие включает/выключает режим, двойное открывает настройки:
расписание, **с / по**, яркость **30 / 35 / 40%** и «Готово». Для времени нажмите
строку, вращайте колесо шагом 15 минут и подтвердите. По умолчанию 23:00–07:00,
35%, расписание выключено. Интервал ежедневный, по местному времени, включая
полночь; равные границы не включают режим на весь день. Без достоверного времени
автоматика не запускается. Ручное переключение действует до следующей границы
расписания; расписание и яркость сохраняются после перезапуска.

Во время сна AOD включён, его яркость соответствует выбранным 30–40%.
Обычные настройки экрана сохраняются. Будильник, окончание таймера и запрос
Bluetooth PIN по-прежнему привлекают внимание. Это режим экрана, без измерения
сна и автоматического подавления уведомлений.
