# Браузер

Отдельное приложение в меню; результаты поиска DuckDuckGo открываются здесь.
HTML разбирается на Gateway, а часы самостоятельно переносят и рисуют текст
под прямоугольный экран 240×280. Google OAuth для браузера не нужен.
Gateway должен работать и быть доступен по Wi-Fi.

Поддерживаются HTTPS, заголовки, абзацы, списки, жирный текст, блоки кода,
простые таблицы в виде строк, ссылки, якоря и изображения. Кодировки берутся
из HTTP/HTML, по умолчанию UTF-8. Относительные адреса учитывают конечный URL
после перенаправлений и `<base>`. Скрытые блоки и скрипты исключаются.
Это режим чтения HTML: CSS-вёрстка, JavaScript, формы, авторизация на сайтах,
видео и загрузка файлов пока не поддерживаются.

Колесо выбирает строки; нажатие открывает ссылку/изображение, на обычном тексте
открывает меню. Двойное нажатие открывает меню с любой строки. Там есть адрес,
назад/вперёд, обновление, смена темы, главная и выход. Кнопка «Назад» возвращает
из просмотра картинки или к предыдущему сайту; выход из браузера, открытого
поиском, возвращает к результатам. История хранит до 16 посещений до закрытия.

На часах хранится одна часть документа до 2048 символов / 24 блоков, до 256
строк разметки и одно декодированное превью. Картинки загружаются по нажатию:
Gateway уменьшает их до 108×80, RGB565 + zlib, часы показывают их с масштабом 2×.
Документы на Gateway привязаны к устройству: до 12, срок 10 минут, до 3 превью
на документ. После истечения срока страницу можно обновить через меню.

Адреса ресурсов проходят общую проверку Gateway: только публичные HTTPS-хосты,
DNS с закреплённым адресом, проверка каждого редиректа, лимиты размера и времени.
Cookies и Google-токены внешним сайтам не передаются.

Индикатор справа показывает положение внутри текущей части страницы.
Недоступные переходы назад/вперёд отмечены в меню. Отмена первой загрузки
возвращает главную; закрытие освобождает ёмкость буферов истории и разметки.
