# Google Calendar

Код приложения: [main.rs](./main.rs).

Нативный контроллер использует общий менеджер аккаунта, проверяемый TLS-клиент Gateway и ограниченный RAM-кэш. QR требует подтверждения на часах. Нужны настройка HTTPS/OAuth и, для поиска/перевода, отдельные серверные API-ключи. Приложения не показывают фиктивные результаты. [Запуск сервера на телефоне и ПК](../../../../GoogleAuthGateway/README.md). [ТЗ и ограничения](../../../GOOGLE_SERVICES.md).
