# Air Keyboard: первый программный этап

Отдельное приложение **Air Keyboard**, ID 32. MPU6050 ещё не установлен:
сейчас работает **тестовый ввод энкодером**, а не отслеживание положения руки.
Гироскопическое наведение, распознавание толчка, IMU-калибровка и BLE-мышь
пока не реализованы. Экран не заявляет, что датчик найден или откалиброван.

- Поворот энкодера выбирает клавишу; нажатие подтверждает её.
- Двойное нажатие открывает меню. «Назад» возвращает из меню.
- `Sh` включает одноразовую заглавную букву; `RU/EN` меняет раскладку;
  `123/Ab` переключает символы. `_` — пробел, `Ent` — новая строка,
  `Del` — Backspace, `< > Up Dn` — перемещение каретки, `Tb` — табуляция.
- Full показывает всю компактную раскладку. Inline показывает редактор:
  временная буква подсвечивается непосредственно у каретки. До подтверждения
  её нет ни в документе, ни в экспортируемых байтах, ни в очереди HID.
- Документ ограничен 1024 байтами UTF-8. Стрелки перемещаются по кодовым точкам
  Unicode, вверх/вниз — по логическим строкам с сохранением колонки. Это не
  редактор графем и не визуальная навигация по перенесённым строкам.

Вид Full/Inline и RU/EN сохраняются через очередь WFS в `/AirKeyboard.cfg`.
Текст остаётся в ОЗУ; он **не сохраняется автоматически**. «Экспорт» создаёт
`/AirKeyboard.txt`, доступный через «Файлы» и редактор. Уже существующий файл
не перезаписывается: сначала переименуйте его через «Файлы». Экспорт пишет
только подтверждённый текст. При обычном выходе с текстом требуется подтверждение;
Home, блокировка PIN, переход к сопряжению или выключение могут закрыть приложение
и очистить несохранённый черновик. Для перехода к сопряжению с текстом также
запрашивается второе нажатие.

## BLE HID

По умолчанию выбран локальный ввод. В меню доступны:

- только часы;
- только BLE HID;
- часы + BLE: локальный журнал собственных действий, не синхронизация с редактором ПК.

Сначала выполните «Сопряжение Bluetooth», подтвердите пару обычным системным
способом и вернитесь в приложение. Выберите вывод BLE и отдельно включите
«Отправку». Она никогда не включается автоматически, не сохраняется в профиль
и выключается при потере подключения или закрытии приложения.

Используется существующий зашифрованный HID-сервис с key-down/key-up.
«В очереди HID» не означает подтверждение ввода принимающим приложением.
Если приёмник подписан только на media, HID-сервис всё равно откажет в передаче
клавиатурных отчётов; текущий общий BLE-статус не различает эти подписки.

HID передаёт физические коды. Для русских букв на ПК/телефоне должна быть
включена стандартная ЙЦУКЕН, для английских и символов — US QWERTY.
Часы не переключают раскладку ОС автоматически. Символы на других раскладках
могут отличаться. Ctrl/Alt доступны в меню; в совместном режиме их действие
на содержимое внешнего редактора локально не моделируется.

Следующий этап после установки MPU6050 — стенд сырых измерений, запись реальных
движений и оценка дрейфа. Пороги жестов без этих данных не задавались.
Стабильная пространственная XYZ-клавиатура пока не готова.
