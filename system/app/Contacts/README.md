# Контакты Google

Чтение имён, телефонов и адресов email через официальный People API.
Включите People API в Cloud-проекте Gateway. На часах откройте «Доступ Google»,
разрешите contacts.readonly в браузере и подтвердите аккаунт на часах.
Список загружается автоматически при прокрутке, карточка показывает телефоны/email.
[Настройка Gateway](../../../../GoogleAuthGateway/README.md).
