# Сообщения с телефона

Приложение показывает последние SMS/MMS-тексты из подтверждённого моста KDE Connect:
до 12 последних диалогов с ограниченными текстовыми превью. Часы не подключаются
к закрытому протоколу Google Messages for web; RCS и отправка сообщений здесь не реализованы.
Google Сообщения может оставаться приложением SMS по умолчанию на телефоне.

1. Подключите KDE Connect на Android к KDE Connect на компьютере, разрешите плагину
   SMS чтение сообщений. Если устройства не находятся, проверьте доступность
   портов KDE Connect 1714–1764 TCP/UDP в локальной сети.
2. В корне проекта найдите уже сопряжённый телефон:

```sh
node Bootloader/tools/kde_bridge.mjs --list
node Bootloader/tools/kde_bridge.mjs --device ID_ТЕЛЕФОНА
```

3. На часах откройте «Телефон» и подтвердите совпадающий код моста. Затем откройте
   «Сообщения». Мост обновляет превью примерно каждые 30 секунд. Колесо выбирает
   сообщение, нажатие открывает текст, «Назад» возвращает список.

При PIN-блокировке или удалении сопряжения моста содержимое в ОЗУ очищается. Новая порция
публикуется целиком: прерванная передача не заменяет список частично. Файлы SMS
на диск часов не сохраняются. На этой машине нужен `busctl` (systemd); мост
использует D-Bus интерфейс `org.kde.kdeconnect.device.conversations`.
