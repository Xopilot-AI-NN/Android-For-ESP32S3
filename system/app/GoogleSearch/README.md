# Google

Код приложения: [main.rs](./main.rs).

Нативный контроллер использует общий менеджер аккаунта, проверяемый TLS-клиент Gateway и ограниченный RAM-кэш. QR требует подтверждения на часах. Поиск DuckDuckGo работает через HTTPS Gateway без API-ключа; Google OAuth нужен только для связанных сервисов аккаунта. DuckDuckGo может отдельно потребовать проверку серверного клиента. Приложения не показывают фиктивные результаты. [Запуск сервера на телефоне и ПК](../../../../GoogleAuthGateway/README.md). [ТЗ и ограничения](../../../GOOGLE_SERVICES.md).
[Архитектура](../../../../ARCHITECTURE.md).

Результаты открываются в [браузере HTML](../Browser/README.md), с сохранением списка поиска при возврате.
