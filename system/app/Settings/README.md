# Настройки

Нативный пакет Rust. Код и интерфейс: [activity.rs](./activity.rs), [bluetooth.rs](./bluetooth.rs), [diagnostics_page.rs](./diagnostics_page.rs), [main.rs](./main.rs), [memory_page.rs](./memory_page.rs), [preferences.rs](./preferences.rs), [system.rs](./system.rs), [wifi.rs](./wifi.rs).

Пакет компилируется в исполняемый файл Firmware. Это исходники приложения, а не динамически загружаемая программа. Подробнее: [архитектура](../../../../ARCHITECTURE.md).
