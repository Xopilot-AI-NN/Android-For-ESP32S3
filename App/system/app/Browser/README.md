# Браузер на часах

Браузер больше не обращается к GoogleAuthGateway. ESP32 самостоятельно выполняет
DNS и HTTPS, получает HTML, разбирает его в текстовые блоки, переносит строки,
открывает ссылки и декодирует изображения. Google-аккаунт, ключ устройства,
домен и постоянно работающий сервер ПК/телефона для браузера не нужны.
Нужны Wi-Fi с интернетом и корректное время для проверки сертификатов.

## Управление

Внизу **Главная / Поиск / История**. Колесо сразу меняет вкладку, нажатие входит
в ввод или список; «Назад» возвращает фокус вкладкам. Адрес можно вводить без
`https://` — схема добавится автоматически. URL-клавиатура начинается с EN,
поисковая с RU; общий переключатель языка и шесть подсказок сохранены.

Поиск идёт напрямую на публичную HTML-версию DuckDuckGo, без API-ключа.
Результаты содержат домен и описание. CAPTCHA/отказ провайдера показываются
сообщением, а не обходятся. «Назад» с первой страницы внутреннего поиска
возвращает его результаты.

В документе колесо выбирает строки. Нажатие открывает ссылку или картинку,
на обычном тексте — меню. Двойное нажатие: адрес, назад/вперёд, обновление,
тема, главная и выход. Загруженные части документа доступны без нового запроса.
История хранит до 16 посещений в RAM; четыре документа остаются разобранными.
При возврате к вытесненному документу его URL загружается заново. Закрытие
браузера или блокировка часов очищает документы и превью из службы.

## Поддержка страниц

Есть заголовки, абзацы, базовый жирный текст, списки, ссылки, `<base>`, разделители,
простые таблицы строками, alt-подписи изображений и числовые/основные HTML-сущности.
Комментарии, script/style/noscript/svg/template и простые скрытые блоки исключаются.
Поддерживаются относительные ссылки и до пяти HTTPS-перенаправлений.

Это **режим чтения**, без JavaScript, полной CSS-вёрстки, форм, cookies,
авторизации на сайтах, видео, аудио и загрузки файлов. Отказ Google-входа через
этот браузер не решён. Кодировки: UTF-8 и Windows-1251 из HTTP-заголовка;
прочие явные кодировки отклоняются. Якоря пока возвращают начало документа.

Картинки загружаются по нажатию. Используются те же собственные JPEG/PNG-декодеры,
что в галерее, без Node/Python/Pillow на сервере. Превью RGB565 108×80 с сохранением
пропорций внутри рамки. JPEG — baseline, PNG — 8-bit RGB/RGBA/Gray/GrayAlpha/Palette,
без Adam7; GIF/WebP/SVG и прогрессивный JPEG не декодируются. Сетевые картинки
ограничены 4 Мп и размером HTTP-тела 192 КиБ. В RAM хранится одно превью. Сетевые PNG накладываются на белый фон, чтобы
чёрные значки с прозрачностью оставались видимыми.

## Пределы и HTTPS

- Заголовки до 8 КиБ, HTTP-тело до 192 КиБ, распакованный gzip до 192 КиБ.
  Большие текстовые страницы показывают ограниченный префикс с сообщением.
- Документ: до 256 блоков, 48 КиБ текста, 64 ссылки и 16 КиБ адресов ресурсов.
  В части документа до 16 блоков; растеризатор ограничен 256 строками.
- Только публичный IPv4/HTTPS, порт 443. Проверяются и URL, и полученный DNS-адрес
  на каждом переходе. Адрес закрепляется в TCP-соединении. LAN, localhost,
  URL с логином/паролем, HTTP и нестандартные порты отклоняются.
- Полная проверка CA, имени сайта и времени. Публичный Mozilla CA bundle из curl
  встроен в прошивку; источник и SHA записаны рядом с `cacert.pem`. Его обновление
  требует новой сборки. TLS-проверка не отключается.
- HTTP/1.0/1.1, Content-Length, chunked и завершение соединением; identity/gzip.
  Cookies, Google-токены и Gateway credentials в публичные запросы не попадают.
  TLS обрабатывается совместно с системным сетевым циклом, по одному запросу.

Исходники: `Firmware/src/services/browser.rs`, папка `browser/`, общий
`net/google_client.rs`, `google_tls.rs`; интерфейс — файлы рядом с этим README.

**Отдельно от браузера:** приложения Google пока используют прежний Gateway.
При запуске `./flash pc` системный образ по-прежнему поступает с ПК через USB;
для отключения самого ПК нужна рабочая загрузка прошивки с microSD. PC block
server не обрабатывает HTML и не выполняет поисковые запросы за часы.

DNS: сначала используется DNS сети. При ошибке/локальном ответе либо ожидании
дольше 3,5 секунды часы сами запрашивают Cloudflare DNS-over-HTTPS через
`cloudflare-dns.com` с bootstrap IP `1.1.1.1`. Сертификат DNS-службы тоже проверяется.
Её JSON-ответ должен соответствовать имени запроса и содержать публичный A-адрес.
Это разрешение имени, не сервер обработки страниц. [Протокол Cloudflare](https://developers.cloudflare.com/1.1.1.1/encryption/dns-over-https/make-api-requests/dns-json/).

### Читаемость страниц

Границы `<a>` больше не разрывают предложение: обычный текст, ссылка и
завершающая пунктуация собираются в общий поток. Строка со ссылкой подчёркнута
и нажимается целиком. Две разные ссылки разделяются на выбираемые строки,
чтобы колесо могло выбрать каждый адрес. Выбранная строка выделена фоном.
Между абзацами и заголовками есть интервалы; список получает текстовый маркер
`-` рядом с содержимым. Пустые `|`, `][` и маркеры не занимают отдельные строки.
Ячейки таблиц отделяются границами потока, без искусственных строк-разделителей.
Это по-прежнему адаптация HTML для чтения, без выполнения JavaScript и полной CSS.
