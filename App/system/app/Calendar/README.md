# Календарь

Одно приложение объединяет локальную сетку месяца и Google-события.
Колесо меняет месяц, нажатие возвращает к сегодняшнему, два нажатия открывают
экран Google для выбранного месяца и переключают обратно. «Назад» закрывает
вложенные экраны Google, затем возвращает к сетке. Для событий нужен настроенный
[Gateway](../../../../GoogleAuthGateway/README.md); сетка доступна без сети.
Старый пакет Google Calendar сохранён для совместимости, второй иконки в меню нет.

Код: [main.rs](./main.rs), [utilities.rs](./utilities.rs).
