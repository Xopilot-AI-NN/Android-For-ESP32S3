# Приложения часов

Здесь находится реальный код приложений Rust: контроллеры, экраны и манифесты.
[Каталог](catalog.json) содержит все 18 приложений меню и системные пакеты.

- [system/app](system/app) — приложения, включая файлы, редактор и настройки.
- [system/priv-app/SystemUI](system/priv-app/SystemUI) — системный интерфейс и Activity Manager.
- [src](src) — общий каталог компонентов и диспетчер состояний приложений.
- [shared](shared) — общие модели без копирования между приложениями.

Исходники компилируются с Firmware; отдельно устанавливаемые Rust/APK-пакеты
пока не поддерживаются. Манифесты описывают native-rust, а не Rhai-заглушки.
Сборщик Firmware берёт пакеты из этого каталога, второй копии пакетов нет.

Подробности, границы слоёв и команды: [архитектура](../ARCHITECTURE.md).
