# Превью интерфейса прошивки

[Общий лист](firmware-device.png) собран из шести снимков framebuffer
**подключённых физических часов ESP32-S3**. Съёмка: 4 ноября 2026 года,
часовой пояс Europe/Minsk. Каждый исходник — 240×280 пикселей.

| Экран | Исходный PNG |
|---|---|
| Циферблат | [watch.png](device/watch.png) |
| Меню приложений | [launcher.png](device/launcher.png) |
| Будильник, таймер и секундомер | [clock-tools.png](device/clock-tools.png) |
| Настройки | [settings.png](device/settings.png) |
| Календарь | [calendar.png](device/calendar.png) |
| Браузер | [browser.png](device/browser.png) |

Кадры получены командой `screencap` через USB PC-мост. Снимок записывается
в зарезервированную область `userdata+1MiB`; экспорт проверяет заголовок
SHOTv1 и CRC и переводит RGB565 в PNG. Для съёмки использована отдельная
приватная копия рабочего дискового образа. Flash-прошивка часов не менялась.
Это снимки цифрового буфера, а не фотографии оптических свойств LCD.
Контрольные суммы PNG: [captures.json](captures.json).

На общем листе добавлены только рамки и подписи; исходные пиксели экранов
вставлены в масштабе 1:1. Пересобрать лист можно из корня репозитория:

```sh
python3 tools/build_readme_preview.py
```

Нужны Pillow и DejaVu Sans в стандартном каталоге Linux. Скрипт не подключается
к часам и проверяет, что все исходники имеют размер 240×280 и попали в лист
без изменения пикселей.

## Как получить отдельный кадр

При работающем PC-мосте выберите нужный экран на часах, дождитесь завершения
анимации, затем выполните:

```sh
python3 Bootloader/zadb.py shell screencap
```

После штатной остановки моста сохранённый кадр можно экспортировать из его
дискового образа штатной утилитой; не подставляйте путь к другому образу:

```sh
python3 Bootloader/tools/watch_assets.py --image ПУТЬ_К_ОБРАЗУ screenshot frame.png
```

Отдельное [превью Air Keyboard](../air-keyboard/preview.png) построено host-версией
того же RGB565-рендерера на синтетическом тексте. Это программный стенд нового
приложения; в этой сессии его на подключённые часы не устанавливали.

[Два новых варианта компоновки «Часов»](layouts/README.md) — программные макеты для сравнения.
