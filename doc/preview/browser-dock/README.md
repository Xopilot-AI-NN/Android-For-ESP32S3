# Браузер и сон · 5 ноября 2026

[Общий лист](preview.png) и отдельные PNG получены host-сборкой настоящего
RGB565-рендерера. Каждый экран 240×280, без изменения масштаба и обработки
пикселей. Адреса, описания и история синтетические. Проверка на устройстве
не выполнена: USB-порт часов в этой сессии отсутствует.

Сценарии в `Firmware/tools/render_watch.rs`: `browser`, `browser-search`,
`browser-keyboard`, `browser-history`, `bedtime-settings`, `clock-tab-bedtime-on`.

Колесо меняет вкладку браузера, нажатие входит в ввод или список. Внутри списка
колесо выбирает запись; «Назад» возвращает вкладки. В документе двойное нажатие
открывает меню. Общая клавиатура закрывает нижнюю часть страницы, поле ввода
находится выше её панели, доступны до шести словарных подсказок.

Часы: выбор вкладки немедленно показывает содержимое. На вкладке сна нажатие
переключает режим, двойное открывает расписание «с / по» и яркость 30–40%.
AOD включается вместе с режимом сна. Настройки времени сохраняются.
